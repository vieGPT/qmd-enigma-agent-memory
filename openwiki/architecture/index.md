# Files

- [Design Decisions and Repository Progression](design-decisions.md) - Records the reasoning behind non-obvious QMD code choices (DNS-rebinding guard, project-local trust gating, scoped BM25, missing-root protection, partitioned vectors, metadata filtering, Metal residency workaround) with code locations, cited issues, and how the repository has evolved.
- [Indexing and Update Pipeline](indexing-pipeline.md) - Traces qmd update and reindexCollection from collection config and trust gating through file scanning, hashing, title extraction, document upsert, deactivation, orphan cleanup, vector copying, and the embed lock. Use it to understand how the index changes on disk and where embeddings are produced.
- [Source Map](source-map.md) - Maps each owned module under src/, bin/, scripts/, tools/ and test/ to its responsibility, with the key function anchors in the large store module, so a contributor or agent can find the right file for a change.
- [Storage Schema and Vector Layout](storage-schema.md) - Documents the QMD SQLite store - document and content tables, the FTS5 index, the partitioned sqlite-vec vector layout and its legacy-to-partitioned migration, collection and context tables, the LLM cache, and the user_version-gated migrations that evolve them.
- [System Overview](system-overview.md) - Explains QMD's layered architecture, from the bin/qmd launcher through the CLI, MCP and HTTP server, SDK createStore facade, internal SQLite Store, LlamaCpp runtime, YAML collections config, and project-local trust gate, and how these layers connect.
